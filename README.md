# javtamnanloo.github.io

Source of [javtamnanloo.github.io](https://javtamnanloo.github.io), built with Jekyll and the [al-folio](https://github.com/alshedivat/al-folio) theme (MIT licence, see `LICENSE`). `_layouts/bib.liquid` and `assets/css/main.scss` are modified copies of theme files. Pushing to `main` builds the site into the `gh-pages` branch, which GitHub Pages serves.
